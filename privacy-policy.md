# Política de Privacidad de Click2Cash

Click2Cash está diseñada para proporcionar conversiones de precios a moneda local directamente sobre las páginas web visitadas por el usuario. Para cumplir esta finalidad única, la extensión obtiene la dirección IP y la ubicación general del usuario, exclusivamente para identificar la moneda local y mostrar conversiones de precios.

## Qué datos recopilamos

- **Dirección IP / Ubicación:** La extensión consulta servicios externos (ipapi.co) para obtener la ubicación aproximada del usuario. Esta información se utiliza solamente para determinar la moneda local.
- No se recoge ningún otro dato personal ni de identificación.
- No se rastrea el historial de navegación, ningún tipo de actividad, ni otra información personal.

## Uso y almacenamiento de datos

- La información sobre la ubicación se utiliza únicamente de forma local y transitoria para mostrar los precios en la moneda correspondiente.
- No vendemos, compartimos ni transferimos datos de usuario a terceros, fuera del caso práctico aprobado.
- No usamos estos datos para ningún fin distinto de la finalidad única de la extensión.

## Seguridad

- Click2Cash no almacena datos personales identificables.
- La extensión opera de acuerdo con las políticas de seguridad y privacidad de Chrome Web Store.

## Cambios en la política

Si se realizan cambios en la política de privacidad, se actualizará este documento y se notificará a los usuarios a través del Chrome Web Store.
